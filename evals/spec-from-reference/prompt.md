/kstack:intent-spec 架空の市立図書館の貸し出しアプリに、予約の機能を足す仕様書を書いて。他社の図書館アプリ（下の「参考」）を参考にしたい。

リポジトリの `docs/glossary.md`：

```markdown
# 用語集
- 利用者：図書館のカードを持つ人。「ユーザー」「会員」とは書かない
- 資料：本、雑誌、CD など、貸し出せるもの
- 貸出：利用者が資料を借りること
- 返却期限：貸出の日から 14 日後。休館日なら次の開館日
```

リポジトリの `docs/features.md`（feature map）：

```markdown
| ID | 機能 | 説明 |
| --- | --- | --- |
| F-01 | 貸出 | カウンターかセルフ機で資料を貸し出す |
| F-02 | 返却 | 返却を受け付け、返却期限を過ぎていれば延滞を記録する |
| F-03 | 延長 | 返却期限の前に、1回だけ 14 日延ばす |
```

参考（他社の図書館アプリの公開ヘルプから、人がまとめたもの）：

- 貸出中の資料に、順番待ちの予約を入れられる
- 順番が来たら、メールと SMS で知らせる
- 取り置きは 7 日。過ぎたら次の人に回す
- 月額の有料会員は、順番待ちの先頭に入れる
- 予約が入っている資料は、延長できない

人しか知らないことは、先に答えておく。

- 目的：貸出中の資料を借りたい利用者が、窓口に何度も問い合わせている。その手間を無くしたい。
- 成功の定義：貸出中の資料に予約を入れられ、返却されたら、順番の先頭の利用者に知らせが届く。
- 変えてはいけないもの：返却期限の計算と、延滞の記録（F-02）。うちの図書館は無料で、料金を取る機能は入れない。

取り置きの日数は、まだ館で決めていない。

この作業場所には書き込めないので、仕様書は全文を返答に出して。
