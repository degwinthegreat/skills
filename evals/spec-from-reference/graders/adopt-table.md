返答には、仕様書の外の要約と、コードブロックの中の仕様書の本文がある。仕様書の本文（コードブロックの中）を見て判定する。本文に表が無いときだけ、本文の外の表を見る。

次をすべて満たせば合格。

- 参考の機能を 1 行ずつ並べた表がある。列は、機能、扱い、理由の 3 つ。
- 扱いの値は「採る」「採らない」「変える」の 3 つの語で書いている。「変える：メールだけにする」「今は採らない」のように、この語に短い言葉を添えるのはよい。人が決めるまで決められない機能だけは「保留」でもよい。ただし、その行が未決の問い（Q1 などの番号か、問いの中身）を指していること。
- 未決の問いを指さない「保留」や、「採用」「一部採用」「不採用」「未決」「案として載せる」など、ほかの語を扱いの値に使っていれば不合格。

判定に関係しないこと：どの機能をどの扱いにしたか。理由の長さ。表の位置。
