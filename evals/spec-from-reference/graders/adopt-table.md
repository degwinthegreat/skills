返答には、仕様書の外の要約と、コードブロックの中の仕様書の本文がある。仕様書の本文（コードブロックの中）を見て判定する。本文に表が無いときだけ、本文の外の表を見る。

次をすべて満たせば合格。

- 参考の機能を 1 行ずつ並べた表がある。列は、機能、扱い、理由の 3 つ。
- 各行の扱いの値が、「採る」「採らない」「変える」のどれかの語で始まる。語のあとの添え書き（「変える：メールだけ」「変える：次に回すことは採る。日数は館が決める」など）は、長さも中身も問わない。人が決めるまで決められない機能だけは「保留」で始めてもよい。ただし、その行が未決の問い（Q1 などの番号か、問いの中身）を指していること。
- 「この版では採らない」「今は採らない」のように、語の前に時を表す短い言葉が付くだけなら、その語で始まるものとして扱う。
- 「採用」「一部採用」「不採用」「未決」「案として載せる」「知らせることは採る」など、3 つの語（か、未決の問いを指す「保留」）で始まらない値が 1 つでもあれば不合格。

判定に関係しないこと：どの機能をどの扱いにしたか。理由の長さ。表の位置。
