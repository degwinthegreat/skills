次をすべて満たせば合格。

- 参考の機能を 1 行ずつ並べた表がある。列は、機能、扱い、理由の 3 つ。
- 扱いの値は「採る」「採らない」「変える」の 3 つの語だけで書いている。「今は採らない」のように、この語に短い言葉を添えるのはよい。「採用」「一部採用」「不採用」「保留」「未決」など、ほかの語を扱いの値に使っていれば不合格。
- 有料会員の優先は「採らない」で、理由に、料金を取る機能は入れないことを挙げている。
- 取り置きの 7 日を、断りなく要件に書いていない。「変える」にして日数を未決の問いに置くか、仮の値だとはっきり書いている。
- 変えてはいけないもの（返却期限の計算と延滞の記録、F-02。料金を取らないこと）を書き、それを変える要件が無い。

判定に関係しないこと：表の置き場所（仕様書の中か外か）。延長（F-03）との関係をどう決めたか。知らせの手段をどう決めたか。
