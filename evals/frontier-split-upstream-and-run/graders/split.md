次をすべて満たせば合格。

- 設計の JSON が返答にある（段・ノード・矢印・役割・スキル・ツールが読み取れる）。
- 上流のスキル（team-principles、spec-writer、agent-rules）は、プロダクトオーナーかテックリードのノードにだけ付いている。エンジニアのノードに 1 つでも付いていれば不合格。
- タスクの実行が、依頼を書くノード（計画のセッション）と、実装して PR を出すノード（実行のセッション）の、別のノードに分かれている。2 つのセッションの種類が JSON の上で区別できる。
- 実行のノードは、チケットごとに別のセッションで並列に回す形になっている。1 つのセッションで全部のチケットを順にこなす形なら不合格。

判定に関係しないこと：段の名前と数、ノードの id と数、色、計画のノードを誰が持つか、JSON のキーの名前。
