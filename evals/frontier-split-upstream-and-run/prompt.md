/kstack:create-frontier-team 架空の家計簿アプリのチームの流れを設計して。

人しか知らないことは、先に答えておく。

- 役割と人数：プロダクトオーナー 1 人（目的と、やらないことを決める）、テックリード 1 人（規約と設計を決める）、エンジニア 2 人。
- ツール：原則と仕様は Notion、チケットは Linear、コードと PR は GitHub。
- 対象のリポジトリ：example/kakeibo（この作業場所には無い）。

チームが今使っているスキルは次の 6 つ。

- team-principles：方針・目的・やらないことを書く
- spec-writer：仕様書を書く
- agent-rules：エージェントが読む規約を書く
- ticket-split：仕様を、ゴールの決まったチケットに分ける
- run-ticket：チケット 1 つを実装して PR を出す
- pr-review：PR をレビューする

検証と評価のためのスキルは、まだ無い。

この作業場所には書き込めないので、HTML は書かずに、設計の JSON を返答に出して。表とチケットの雛形もあわせて返して。
