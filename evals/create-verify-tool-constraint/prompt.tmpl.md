/{{SKILL_INTENT}} プルリクエストの本文に、画面の変化のスクリーンショットを添えるスキルを作りたい。

方針は、次の内容で私が OK した。

- 解決したいこと：レビューする人が、画面の変化を PR の本文だけで確かめられる。根拠：先月、画面の変化が本文から分からず、レビューが2往復した PR があった。
- 非目標：スクリーンショットを撮る道具は作らない。
- 譲る順：本文の短さ → 確かめやすさ。

たぶん、エージェントからは GitHub の PR に画像を上げられないので、画像は人に上げてもらう手順になると思う。

参照先は読まなくてよい。この方針で、スキルの本文（SKILL.md）の下書きを返答に書いてください。ファイルには書かなくてよい。
