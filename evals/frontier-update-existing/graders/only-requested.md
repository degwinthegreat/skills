- 直したあとの仕様書の矢印は、今の仕様書の 9 本から変わっていない。依頼に無い矢印（たとえば検証から実装への直しの辺）を足していれば不合格。足したほうがよい矢印を、仕様書の外の案として挙げるのはよい。

判定に関係しないこと：CI の待ち時間の上限の扱い、差分の書式（diff か表か箇条書きか）、設計書を直したかどうか、ツールに GitHub Actions を足したかどうか。
