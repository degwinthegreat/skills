/kstack:intent-skill チームの週報を書くスキルを作りたい。週報には、先週マージされた PR の件数と、レビューを待った時間の中央値と、そこから読み取れる仮説を数行入れる。

作るきっかけ：先週、週報を手で書いたら PR の件数を数え間違え、チームの中で訂正が出た。

このリポジトリには、まだ決まりのファイルもプルリクエストも無い。読む手順は飛ばしてよい。方針の下書きまで進め、返答に書いて、私の確認を待ってください。
