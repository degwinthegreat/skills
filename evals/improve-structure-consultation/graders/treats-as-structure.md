組み立てを見直す進め方で答えているかを見る。次の4つをすべて満たせば合格。

1. 変えてはいけないもの（例：外の人がリンクしている ADR の URL、ADR を書き換えない慣習）を、案より先に挙げている。
2. 置き場ごとに、誰が書き、誰（どのスキル・人）が読み、どこまで信じられているかを、表か同じ中身の箇条で整理している。材料にある2つのスキルと ADR が入っている。
3. 案を2つ以上並べ、推奨を1つ示している。
4. 決めたいことを人に聞いて止まっている（答えを待っている）。案を全部実装した差分や、スキルの本文の書き換えを出していない。

一般的な設計の助言だけで、上の 1・2・4 のどれかが欠けていれば不合格。どれか1つのスキルに1行足すことを答えにしていれば不合格。言い回しや、表の列の名前が違うことは問わない。
